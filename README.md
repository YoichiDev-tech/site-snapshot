# Site Snapshot

A lightweight, single-file tool for a quick first look at a website before 
deciding whether it needs a full review.

Open the file in any browser, paste a URL, and run the check.

## What it shows
- Response status
- Approximate response time
- A few public headers (server, content-type, cache-control)

It is intentionally limited. It does not replace a proper audit.

## How to use
1. Open `site-snapshot.html` in a browser
2. Paste the website URL
3. Click **Run snapshot**

No build step. No dependencies. No backend.

## Why it exists
Used internally at PrismWave Studio during outreach to get a fast signal 
on a prospect’s current site before offering the free 15-minute review.
